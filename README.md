# AIUB Canteen Management System

A Software Engineering project developed to streamline canteen operations at the American International University-Bangladesh (AIUB). The system focuses on managing staff accounts, user access, billing, inventory, and order processing through structured workflows.

## Key Features

- **Staff Account Management:** Manage staff accounts and validate account-related operations.
- **Staff Login:** Implement and test authentication workflows, including access control and input validation.
- **Role-Based Access Control:** Define and validate access permissions based on user roles.
- **Billing Management:** Define requirements and test scenarios for billing operations.
- **Inventory Management:** Establish acceptance criteria for inventory-related workflows.
- **Order Processing:** Define and validate order management workflows.

## Software Testing Activities

- Translated project requirements into **20+ acceptance criteria and test scenarios**.
- Tested Staff Login and Staff Account Management functionalities.
- Evaluated access control, input validation, and negative user scenarios.
- Tracked project tasks and changes using Git and Trello.

## Tools & Technologies

- **Version Control:** Git, GitHub
- **Project Management:** Trello
- **Focus Areas:** Software Engineering, Requirements Analysis, Manual Testing, Functional Testing, Test Scenario Design

## Project Objective

To apply software engineering principles and software testing practices throughout the development process, with an emphasis on requirement analysis, workflow validation, access control, and software quality assurance.
